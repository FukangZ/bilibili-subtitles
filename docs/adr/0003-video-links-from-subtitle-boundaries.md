# 保留原片跳转入口，由字幕条目计算时间

## 为什么文章还需要视频

文字便于快速阅读，但字幕没有画面信息。“看右边的图”“刚才这个动作”等讲解不能靠润色补全；识别错误和含糊表达也需要回到原片核对。因此文章保留画面指代，并在章节处提供原片跳转链接，让读者先读文字、需要时再看视频，而不是把文章伪装成完全独立且经过事实核验的材料。

链接指向来源视频的指定分 P 和章节起点，不只回到视频首页。它提供核对入口，不代表模型看过画面，也不证明每句话都与字幕逐字对齐。

## 为什么边界用条目 id，而不是让模型写秒数

字幕条目按输入顺序编号，起始时间单调不减，但允许同秒多条。例如第 41、42 条都始于 `03:12`，仅用秒数无法表示“从第 42 条开始新章”。模型因此选择条目 id，代码将前章结束于第 41 条，并从第 42 条取得 `03:12` 作为新章链接。

条目 id 能唯一定位本次输入内的切分位置；代码生成时间与链接，避免模型在改写后凭印象配时间。代价是 id 随输入有效行重新分配，编辑文件后旧章节计划不能复用。输入的起始时间向下取整到秒，因此链接只提供秒级章节定位，不用于精确字幕同步或剪辑。

代码校验引用是否合法，不判断模型选择的章节起点是否最贴合语义。先固定条目范围、再加工全文的处理方式见 [0002](0002-two-stage-full-transcript-polishing.md)。
